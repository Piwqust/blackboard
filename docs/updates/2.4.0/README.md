# Blackboard Text 2.4.0

Размещение и внешний вид панели рисования из этого отчёта заменены [исправлением 2.4.1](../2.4.1/README.md): компактная полоса рядом со страницами, без изменения вёрстки заметки. Остальные функции сохранены.

Локальное обновление по аудиту от 4 октября. Проверки завершены 6 октября 2026 года. Код не отправлен в GitHub и не опубликован; облачная база и действующий сервис не изменялись.

## Результат

Инструменты рисования раскрываются сверху по центру. Новые штрихи сглаживаются общим алгоритмом редактора, просмотрщика и экспорта. Длинные страницы больше не уменьшают разрешение всей доски. Настройки, темы и появляющийся скроллбар сохранены.

Добавлены маркер, перо с нажимом, прямые линии с Shift, временный ластик с Alt, выделение и перемещение штрихов, изменение их цвета/толщины, ластик целого штриха и кнопка Redo. История рисования включает перемещение, изменение стиля, очистку и пакетное стирание. Перетаскивание настройки цвета/толщины объединяется в один шаг отмены.

Новые аннотации можно привязывать к словам. Вставка текста перед словом сдвигает аннотацию; изменение размера шрифта меняет её по геометрии слова. При удалении/замене слова аннотация становится свободным рисунком. Обычный выбор штриха сохраняет привязку; намеренное перемещение её снимает. Text Undo восстанавливает привязку, потерянную из-за изменения текста.

## Дополнительные возможности

- Закрепление страниц и поиск с фрагментом около совпадения.
- На телефоне список страниц по кнопке, без постоянно зарезервированной правой колонки.
- Сохранение настроек кисти, маркера, пера и ластика отдельно; недавние цвета.
- PNG с текстом и рисунком; многостраничный PDF для длинной заметки. Ластик работает только по слою рисунка и не вырезает текст из экспорта.
- Локальная история страницы: до 25 версий на страницу, 100 суммарно и 10 МБ; фиксация не чаще одного раза в 30 секунд при изменении сохранённой страницы. Восстановление создаёт новую страницу.
- Текстовое описание рисунка в опубликованной копии, доступное визуально и экранному диктору.
- Выбор English / Русский в настройках. Названия заметок, текст, описания рисунков и фрагменты пользовательского содержимого не переводятся. Системный текст неожиданной ошибки может оставаться на языке браузера.
- Отдельный зашифрованный экспорт/импорт ключей управления ссылками. Проверено восстановление в независимом браузерном профиле и отключение ссылки оттуда без повторной загрузки копии.
- Правильное сообщение о заполнении сервиса коротких ссылок и агрегированная информация об остатке лимита через health endpoint. Идентификаторы заметок и ключи туда не попадают.
- Напоминание о переносимой копии в описании хранения внутри настроек, без дополнительной панели над заметкой.

## Совместимость и данные

Локальная база обновлена с версии 1 до версии 2 без удаления страниц и аварийных снимков. Есть отдельный тест этого перехода. История страницы хранится отдельно от текущих страниц и workspace backup.

Новые файлы заметок и опубликованные копии имеют schemaVersion 2. Версия 2.4.0 принимает старые файлы и ссылки версии 1. Предыдущие версии приложения отклоняют формат 2, чтобы не потерять новый тип кисти, нажим или привязку при повторном сохранении. В старых штрихах не меняется тип пути, пока пользователь явно не выбирает сглаживание; исправленный расчёт координат применяется ко всем рисункам.

Ключи ссылок не добавлены в обычный backup. Их отдельный файл защищён AES-GCM и ключом из пароля через PBKDF2 SHA-256, 300 000 итераций. Он содержит метаданные ссылок и ключи, но не payload заметки. Импорт ключей не публикует ничего; конфликт ключей одного ID отклоняется целиком. Уже сохранённые локальные сведения сохраняются. Для неопределённого pending-upload после восстановления ключей доступно отключение; повторный upload возможен только в первоначальном браузере, где есть pending payload.

## Что не проверено

Физическое перо, отклонение ладони устройством, VoiceOver и Safari/iPhone не проверялись. Нажим и второй указатель проверены синтетическими Pointer Events, а не аппаратным вводом. Для подтверждения аппаратного качества нужен один сеанс: быстрые/медленные штрихи, изменение нажима и случайное касание ладонью на целевом устройстве.

PDF экспортирует вид доски как изображения. Текст внутри PDF не выбирается, не ищется и не доступен как текст экранному диктору; для текстовой доступности использовать TXT/Markdown или опубликованную заметку с описанием рисунка. PNG ограничен одной страницей до 8192 px по стороне и 8 млн логических пикселей, PDF до 200 страниц.

Свободные рисунки не обещают автоматического следования за переносами строк: это делает отдельный режим аннотации к словам. Он привязывает к слову, а не к произвольному предложению или абзацу. Замена самого слова сохраняет рисунок свободным, вместо привязки к новому слову по догадке.

Облачный сервис не развёрнут. Для публикации нужно обновить Worker и PWA вместе: старый Worker не принимает schemaVersion 2. Новая D1-миграция не требуется. Возвращать браузер с базой версии 2 в прежнюю версию приложения напрямую нельзя; сохранить копию и восстановить её в версии 2.4.0.
