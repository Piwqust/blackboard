# Выполнение плана Blackboard Text

Дата: 20 сентября 2026. Локальная версия: **2.2.1**.

Этот файл заменяет промежуточный отчёт от 19 сентября. Ранние отметки «готово» перепроверены: некоторые правки не устраняли дефект либо создавали регрессии. Ниже — фактическое состояние после проверки.

## Результат

Исправления внесены для всех **22 BUG**. Пройдены **22 теста ядра**, **37 браузерных тестов**, **3 целевых пропуска** (тест расширения не запускается как PWA и наоборот). Пройдены ESLint, синтаксическая проверка, сборка PWA/расширения и проверка артефактов. Команда npm run verify также успешно выполнена на **Node 22.23.2**, как в CI.

В B1–B7 реализованы первые версии функций. Полная русская локализация и PDF/PNG остаются отдельными этапами исходного плана. Ручные ограничения A9 перечислены в конце.

Изменения закоммичены локально. Push, PR, deployment и обновление установленной пользовательской копии не выполнялись. Данные пользователя в тестах не использовались.

## Техническая часть C и риски R

- ENG-01/05: браузерные проверки включены в validate и release CI. Удалённый запуск CI не заявлен: ветка не отправлена.
- ENG-02: ESLint с ESM flat config проверяет runtime/scripts/tests. Синтаксическая и JSON-проверка сохранены дополнительно.
- ENG-03/04: выделены dialogs, page tools и canvas budget; defaults и нормализация используют core/schema. История текста остаётся в editor.js; массовая переработка не выполнялась.
- ENG-06/07: icon generator исключён из dist; privacy описывает ссылки; LICENSE и Inter-OFL.txt доступны в обеих сборках.
- ENG-08/09: выполнены измерения, без заявления «стало быстрее»: базового замера предыдущей версии нет. Перекодировка шрифтов не сделана без доказанной потребности.
- R-01: bitmap ограничен 8 млн пикселей / 8192 по стороне; огромная ширина/координаты опубликованной доски отклоняются. Длинные доски могут терять чёткость, но точки сохраняются.
- R-02/03: первая установка не вызывает reload; обновление активируется по действию пользователя; кеш разделён по scope.
- R-05: очередь получает копию данных при постановке операции; проверено последующей мутацией объекта.
- R-06: выбор чёрного/белого текста выделения использует границу контраста.
- R-09: File.size проверяется до file.text(), UTF-8 размер — при разборе.

## Доказательства

- verification/node22-verify.txt — Node 22, ESLint, 22 теста ядра, две сборки.
- verification/browser-tests.txt — 37 passed, 3 целевых skipped.
- verification/installed-browsers.json — Chrome 153.0.8010.36 и Edge 153.0.4234.48, DPR 2, измерения layout.
- verification/performance.json — 100/1000 страниц и 10k/100k точек. На этом Mac запись 1000 страниц: 14 мс, чтение: 11 мс. Не гарантия для других устройств; рисование измеряет отправку команд, не завершение GPU.

- tests/browser/runtime.spec.js — настоящий worker и unpacked extension в отдельных временных профилях.

## Ограничения и оставшаяся работа

- Проверены DOM, геометрия и вычисленный контраст. Скриншоты получены, но визуальный просмотр изображений этой моделью недоступен: ручная оценка оформления остаётся отдельной проверкой.
- VoiceOver, физические touch/stylus и настоящий CJK IME не проверены. Проверены клавиатура и программный isComposing.
- Печать/PDF и экспорт PNG не проверены и не предлагаются как готовая функция.
- Аварийное завершение процесса до окончания IndexedDB и полная матрица гонок удаления/очистки R-04 не доказаны. Обычное обновление, импорт, отмена и ошибки записи покрыты.
- Установка PWA отдельным окном ОС и обновление пользовательского профиля не выполнялись. Проверены регистрация worker, offline reload и waiting update в изоляции.
- Полный русский интерфейс остаётся самостоятельным этапом.

Завершена локальная реализация функционального пакета. Это не утверждение о прохождении всех ручных приёмочных проверок или публикации релиза.
