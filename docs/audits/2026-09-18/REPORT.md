### BUG-01 · P1 · Ссылка в опубликованной заметке может выполнить JavaScript

**Область:** PWA, read.html; требуется нажатие на подставленную ссылку. **Категория:** Безопасность.

**Как воспроизвести:** Открыть локальную заметку с href, содержащим java + перевод строки + script. Нажать тестовую ссылку. Браузер нормализует адрес до javascript: и выполняет его.

**Подтверждено:** Безвредный маркер window.__bbAuditXss стал true. Код выполнялся на origin редактора, где доступна IndexedDB.

**Последствие:** Присланная заметка получает возможность читать или менять данные этого сайта. Проверка не читала личные заметки и не отправляла их наружу.

**Исправление:** Заменить список запрещённых тегов на разрешённый набор элементов и атрибутов; проверять протокол URL после нормализации управляющих символов. Для чтения чужих заметок применить отдельную строгую политику и CSP. Изоляцию на другом origin рассмотреть как дополнительный барьер.

**Критерий готовности:** В настоящем DOM безвредные XSS-пробы с переводами строк, табуляцией, сущностями и вложенной разметкой не выполняются. Разрешённое форматирование сохраняется.

### BUG-02 · P1 · Чужая заметка инициирует посторонние запросы при открытии

**Область:** PWA, опубликованные заметки; нажатие не требуется. **Категория:** Приватность.

**Как воспроизвести:** Открыть синтетическую заметку с img srcset, CSS background-image и video poster на второй локальный origin.

**Подтверждено:** Зафиксированы три GET-запроса к 127.0.0.1:4179. Удаление только src и xlink:href не закрывает другие способы загрузки.

**Последствие:** Автор может узнать об открытии ссылки, вопреки обещанию в Privacy. Подтверждены запросы, не утечка содержимого заметок.

**Исправление:** Запретить в reader все источники загрузки вне разрешённого набора, включая srcset, poster, CSS url(), SVG и вложенные документы. Не полагаться только на проверку строк src.

**Критерий готовности:** Автоматический тест сети после открытия чужой заметки видит только файлы приложения; проверяются и альтернативные атрибуты.

### BUG-03 · P1 · Ошибка обычного автосохранения остаётся незаметной

**Область:** Оба редактора; отказ IndexedDB, например превышение квоты. **Категория:** Сохранение.

**Как воспроизвести:** В отдельном профиле сохранить исходный текст, искусственно запретить readwrite-транзакции и дописать заметку. Дождаться автосохранения, затем перезагрузить.

**Подтверждено:** В IndexedDB остался исходный текст; appStatus был скрыт, индикатор не показывал ошибку. Новое содержимое исчезло после перезагрузки.

**Последствие:** Пользователь продолжает писать, не зная, что изменения не сохраняются.

| IMP-11 | Учитывать «Уменьшение движения» | В CSS нет prefers-reduced-motion; есть blur, перемещения и изменения высоты preview. | При reduce убрать движение/размытие, оставить мгновенное состояние или короткую прозрачность. | Навигация остаётся понятной без обязательной анимации; нормальный режим не меняется. |
| IMP-12 | Точное предупреждение о возможности отзыва и обновления ссылок | Текущая модель — неизменяемая копия в URL, а не живой опубликованный документ. | Сохранить локальную модель, назвать действие «Поделиться копией» и пояснить необходимость новой ссылки после правки; «обычно помещается», не «для любого чата». | Пользователь ожидает копию, не синхронизацию или отзыв. Backend ради отзыва без отдельного решения не добавлять. |

Первыми после багов рекомендованы IMP-01, IMP-02 и IMP-03: они улучшают чтение, поиск и восстановление, не превращая блокнот в новую систему аккаунтов и облака. ## Что сохранить

- Мгновенное открытие редактора, отсутствие обязательной регистрации и платных служб.
- Раздельное хранилище PWA/расширения и перенос через явный экспорт, без молчаливой синхронизации.
- Web Locks в поддерживаемом Chromium, резервные snapshots и сохранение старого Chrome storage.
- Формат backup с версией, обработку одинаковых ID страниц и ограничение распаковки опубликованного текста.
- Генерацию офлайн-списка из реального dist и понятное объяснение неизменяемой копии в URL.
- Существующие темы, страницу без лишних карточек, preview по фокусу и клавиатурное переключение страниц.

## Что остаётся непроверенным

Не выполнены: реальный Microsoft Edge, установка PWA через системный интерфейс, физический iPhone/Android, Safari, VoiceOver, 400% zoom, реальные пользовательские миграции, восстановление после выключения питания, большое хранилище и ограничения памяти, доставка длинных ссылок через конкретные мессенджеры, финальные CI и production-deploy. Скриншоты требуют человеческого просмотра. Это не сертификат отсутствия остальных ошибок и не полная проверка WCAG.
