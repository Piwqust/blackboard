Privacy

Your notes stay local.

Your working notes stay in this browser. Blackboard Text has no user accounts, analytics or automatic note sync. Short links use an optional online store only for copies you explicitly share.

What is stored

Pages, drawings, settings, and recovery snapshots live in IndexedDB for the current browser profile and origin. The Edge extension may read legacy unpacked-extension storage only to copy it into this local workspace; it does not upload it.

What leaves the browser

GitHub Pages serves the app files. It does not receive your note contents. Creating a short link sends a selected copy to the configured Cloudflare sharing service. A downloaded .blackboard.json backup is created only when you choose Export and is controlled by you.

Short links

Creating a short link uploads the selected copy to Cloudflare. Text, selected drawings and appearance are stored until you disable the link or the service owner removes it. Anyone with the link can read the copy. There is no public list of notes, but the service operator can access stored copies.

A separate management key stays in this browser. It lets you disable the link and is never included in the recipient link or workspace backup. Clearing browser data loses those controls. Disabling removes the stored note payload; a record of the disabled ID remains to prevent retries from bringing it back. Copies already saved by recipients cannot be recalled.

Cloudflare processes network information such as IP addresses for request handling and rate limits. The application does not store these in its note database. Short-link responses are not cached for offline reading. Full links remain available when you do not want to upload a copy.

Full links

Publish page embeds a copy of the note in the link after the # character. That part is not sent to the hosting server. Anyone with the link can read the copy; later edits do not update it, and it cannot be revoked. Only share it with people who should read the note.

The reader removes active markup and automatic external resources before displaying a note.

Keeping a copy

Clearing site data, uninstalling an extension, or deleting a browser profile can remove local data. Export a backup before doing any of those things.
